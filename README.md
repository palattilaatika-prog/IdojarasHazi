Meteo app:
A Java Swing desktop application that displays current weather data using the free Open-Meteo API.
Displays current temperature, wind speed, and measurement time
Allows the user to select a city
Retrieves real weather data from Open-Meteo
Includes a mock weather service for offline testing
Supports intentional errors for testing error handling
Uses SwingWorker to perform requests in the background
Displays errors using JOptionPane
Includes JUnit 5 and Mockito tests
Used ai to work out the testing logic, JsonParseing and plantUML image generation.
